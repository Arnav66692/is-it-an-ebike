## Notes on the fields

- Battery size was computed as volts times amp-hours for 22 models, and each quote says so. These are ariel-rider-x-class-60v-off-road, himiway-a7, himiway-d5-2-0, himiway-d5-2-0-20-inch, himiway-d5-2-0-st, hover-1-h-1-pro-series-compass, mokwheel-asphalt, mokwheel-flint, mokwheel-flint-pro, mokwheel-mesa-plus-st, mokwheel-tor-plus, pedego-boomerang-core, pedego-boomerang-pro, pedego-cargo, pedego-element-core, pedego-element-pro, pedego-moto, pedego-ridge-rider-2025, ride1up-700-series, ride1up-revv1-fs, velotric-t1, velotric-triker.
- weight_lb is null for 26 models. For the five Lectric models the page gives a weight only without the battery. For Mokwheel Slate, Blix Vika X and Heybike Venus the page gives conflicting weights. For Ride1Up TrailRush the only weight is inside a customer review, which was not used. For the rest the page gives no bike weight.
- classes lists every class the page names, including classes reached by a setting, an app unlock or an optional throttle kit, so it can be wider than the class the bike ships in. The clearest cases are Aventon Current ADV, Current EXP, Current LTD, Level 4 ADV, Pace 4 and Aventure M, Heybike Ranger 3.0 Pro, Saturn, Hybrid and Venus, Blix Vika X, and the Pedego bikes marked Class 3 Ready. Aventure M, Level 4 ADV and Ramblas ADV have no throttle as sold, so throttle is false for them.
- top_assist_mph is the highest speed the page states for the bike, including speeds the maker says are unlocked in the app. Velotric Go 1, Packer 1 and T1 are listed at 25 mph because the page gives 25 mph as the unlocked speed.
- Where several versions share one page, the first listed version was used. Ariel Rider X-Class 60V is the Off-Road edition with one 60V 20Ah battery, and the Performance edition on the same page was not added. Heybike Saturn uses the single battery version. Juiced Scrambler uses the full-suspension weight. Velotric Nomad 1 Plus uses the high-step weight.
- Juiced Bikes now sells only the Scrambler. The RipRacer, Scorpion X2 and HyperScorpion links redirect to the home page and the RipRunner and CrossCurrent X links return 404.
